# Context, glossary, and speakers

Read when working on meeting context, names/terminology, glossaries, participants, diarization, or speaker attribution.

Aim to discover context and participants automatically when technically and legally available; allow user-provided context and terminology. Use a glossary as supporting evidence, not as an unconditional replacement list.

Distinguish diarization (`speaker_1`, `speaker_2`) from real-world identity. Represent uncertainty with confidence or unknown states. Do not require manual names when automatic discovery is available, and never assign an identity without evidence.
